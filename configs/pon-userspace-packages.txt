# ---- NFS 客户端用户态（内核 kmod 由 fw-build 出，这里只出 mount.nfs 等工具）----
# 顺序：先编依赖库 libnl，再编 nfs-utils（DEPENDS: libtirpc libuuid libnl-core libnl-genl）
# libnl 是主仓内置包（package/libs/libnl），不在 packages feed 里，路径不能写 package/feeds/packages/libnl
# （feed 里没有该目录，脚本会按“源码目录缺失”判 FAIL，而 libnl-core apk 其实已作为 nfs-utils 依赖编出来了）
# 第二列必须写**真实 apk 包名**：该 Makefile 里 ABI_VERSION:=200，apk 打包后包名变成
# libnl-core200 / libnl-genl200（产物 bin/packages/.../libnl-core200-3.12.0-r2.apk）。
# 脚本按 "${apk}-[0-9]*.apk" 精确前缀匹配，写 libnl-core 会匹配不到而误报“没产出 apk”。
package/libs/libnl|libnl-core200|required
package/libs/libnl|libnl-genl200|required
package/feeds/packages/nfs-kernel-server|nfs-utils|required
