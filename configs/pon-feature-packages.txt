# 包 -> 能力索引的归类规则
# ------------------------------------------------------------------------------
# 格式：<能力>|<包名通配，空格分隔>（一行一条，不支持换行续写）
# 能力名必须与 apk 仓库目录 aarch64_cortex-a53/ponwrt-k<内核版本>/<能力>/ 一致；
# common 是兜底：没有命中任何规则的包一律进 common（不会因为规则漏写而丢包）。
# 规则按文件顺序匹配，先命中先归类，所以 usb 必须写在 wifi 前面。
#
# 新增能力（例如 bt）时：这里加一行规则 + configs/device-features.txt 给对应机型加
# 该能力，就能生效，工作流不用改。
# ------------------------------------------------------------------------------

# USB 栈 + USB 总线上的无线网卡（插 USB 网卡用）
# 注意：kmod-rtw88-*-au / kmod-mt76x0u 这类必须先于下面的 wifi|kmod-rtw88-* /
# kmod-mt76* 命中，否则会被归到 wifi 目录，无内置无线的机型就看不到它们。
usb|kmod-usb-* kmod-*-usb-* usbip-* usbutils-* uvc-* libusb*-* usbmode-* kmod-rtw88-*-au kmod-rtw88-8723du kmod-rtw88-8821cu kmod-rtw88-8822bu kmod-rtw88-8822cu kmod-rtl8xxxu kmod-rtl8188eu kmod-rtl8192cu kmod-rtl8192du kmod-mt7601u kmod-mt76x0u kmod-mt76x2u kmod-mt7663u kmod-mt7921u kmod-ath9k-htc kmod-carl9170
# 无线（内置 WiFi 驱动、hostapd/wpa 等用户态）
wifi|kmod-rtw88-* kmod-rtl8* kmod-mt76* kmod-ath* kmod-iwlwifi* wireless-regdb wpa-supplicant hostapd iw
# 蓝牙
bt|kmod-bt* kmod-bluetooth* bluez-* luci-app-blue*
