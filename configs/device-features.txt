# 机型 -> apk 仓库能力索引
# ------------------------------------------------------------------------------
# 格式：<board_name>|<能力1> <能力2> ...
# 能力名对应 apk 仓库目录：aarch64_cortex-a53/ponwrt-k<内核版本>/<能力>/
#   common —— 所有机型都挂（用户态 + 与硬件无关的 kmod），不需要写在这里
#
# 规则：
#   1) 没列出的机型只挂 common（安全默认，不会误装硬件相关的包）；
#   2) 新增机型（例如「有 USB 无 WiFi」）只需加一行 `xxx|usb`，不用改任何工作流；
#   3) 能力判断是编译期写进镜像的，改了这张表要重编固件才生效（设备侧也可手动改
#      /etc/apk/repositories.d/90-ponwrt-apk-repo.list 临时加源）。
#
# 现状依据（源码级）：
#   - configs/release.config 把 kmod-mt7915e / kmod-mt7916-firmware 设成 =y（无线
#     驱动内置进镜像，不需要在线装），所以 HG5585F-CT / HG5382A 都不需要 wifi 能力；
#   - configs/an7581.config 里 kmod-usb-* 是 =m（可在线装），USB 栈只给带 USB 的机型挂；
#   - HG5382A 镜像不含 USB 驱动栈，因此不给它挂 usb 源；
#   - Nokia XG-040G-MD（nokia_xg-040g-md-ubi）有 USB、无内置无线：工作流会按机型
#     关掉 release.config 的 mt7915e/mt7916，USB 栈与 USB 无线网卡驱动都走 usb 能力。
# ------------------------------------------------------------------------------
