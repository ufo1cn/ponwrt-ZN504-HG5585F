# build-packages-legacy.yml 的编译清单
# 目的：把"旧仓（PonWrt-HG5382A）有、新仓（ponwrt-ZN504-HG5585F）没有"的用户态软件，
#       在新仓同一内核源码树上用固定私钥重新编成 apk，产物发布到 ufo1cn/ponwrt-apk-repo。
#
# 格式：auto|<apk 包名>|<required 或 optional>
#   auto = 由 workflow 自动解析源码目录（先按目录名，再按 Makefile 里的 Package/<apk>，
#          最后按 PKG_NAME 反查），不写死 feeds 路径。
#
# ⚠ 已剔除"固件本来就内置"的包（避免与镜像内 =y 版本重名）：
#   查证来源：configs/an7581.config / configs/release.config / configs/pon-packages/*.config
#   · configs/an7581.config  : luci-app-ddns、ddns-scripts、ddns-scripts-cloudflare、luci-theme-argon
#   · configs/release.config : luci-app-cpufreq、luci-app-diskman、luci-app-ttyd、ttyd(依赖)、
#                              usbutils、v2ray-geoip、v2ray-geosite、kmod-wireguard
#   · pon-packages/20-camera-audio.config : alsa-utils、alsa-lib（固件未合并该文件，见下）
#   · pon-packages/30-bluetooth.config    : bluez-daemon/libs/utils、dbus、libdbus、bluez-alsa、luci-app-blueaudio
#   · pon-packages/50-fs-share.config     : kmod-fs-nfs*、nfs-kernel-server(-utils)、nfs-utils(-libs)
#   注意：两个固件工作流只合并 an7581+release，pon-packages 仅供包工作流；
#         因此上面标"固件未合并"的项仍属缺口，但它们由 pon-packages 统一管理，
#         不放进本清单，避免两套来源互相覆盖。
#
# 已刻意排除（与固件内核 ABI 绑定或镜像内重名，重编会冲突，不重编）：
#   · 全部 kmod-*（含 kmod-fs-ksmbd / kmod-fs-nfs* / kmod-wireguard / rtw88 全家 / usb 驱动全家）
#   · audio-support（内核虚拟包）
#   · sing-box（新固件 config 已选）
#   · ksmbd-tools / luci-app-ksmbd（服务端依赖 kmod-fs-ksmbd，该 kmod 不在镜像里也不重编）
#   · libx264（随 ffmpeg 子包产出）
#
