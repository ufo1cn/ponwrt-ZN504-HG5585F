# build-packages-legacy.yml 的编译清单
# 目的：把"旧仓（PonWrt-HG5382A）有、新仓（ponwrt-ZN504-HG5585F）没有"的用户态软件，
#       在新仓同一内核源码树上用固定私钥重新编成 apk，产物发布到 ufo1cn/ponwrt-apk-repo。
#
# 格式：auto|<apk 包名>|<required 或 optional>
#   auto = 由 workflow 自动解析源码目录（先按目录名，再按 Makefile 里的 Package/<apk>，
#          最后按 PKG_NAME 反查），不写死 feeds 路径。
#
# 已刻意排除（会与新仓固件冲突，不重编）：
#   · 全部 kmod-*（kmod-rtw88 全家 / rtl8xxxu / rtl8192cu / usb-xhci / usb-serial-ch341 /
#     usb-net-rtl8152 / asix-ax88179 / video-uvc / usb-audio / sound-core / kmod-wireguard /
#     kmod-fs-nfs* / kmod-fs-ksmbd / kmod-crypto-arc4）
#     → 内核 ABI 与固件强绑定；且 USB 版固件的 USB_PKGS 已把其中大部分 =y 编进镜像，重复装会顶掉镜像内模块。
#   · audio-support（内核虚拟包，固件内已 =y）
#   · sing-box（新仓固件 config 已选，重编会与镜像内版本重名）
#   · ksmbd-tools / luci-app-ksmbd（服务端依赖 kmod-fs-ksmbd，而该 kmod 属上一条不重编，
#     装上也起不来；SMB 服务端改用纯用户态的 samba4-server）
#   · libx264（作为 ffmpeg 的子包一并产出，不单列）
#
